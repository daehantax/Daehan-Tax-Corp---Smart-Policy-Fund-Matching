# 대한세무법인 고객사 전용 페이지 — 검색 결과에 노출되지 않게 한다.
#
# [중요] 여기서 Disallow 로 막으면 안 된다.
# 크롤러가 페이지를 아예 읽지 못하면 index.html 의
#   <meta name="robots" content="noindex, nofollow">
# 를 볼 수 없어서, 오히려 색인 제외가 동작하지 않는다.
# (daehantax.com 에서 이 페이지로 링크가 걸려 있으므로 크롤러는 URL 자체는 알게 되고,
#  내용을 못 읽으면 '정보를 제공할 수 없습니다' 형태로 주소만 검색에 뜰 수 있다)
#
# 따라서 수집은 허용하고, 색인 제외는 noindex 메타가 담당한다.
# 페이지 본문은 사업자번호·대표자명 인증을 거쳐야 나오므로
# 크롤러가 읽어도 빈 화면만 본다.
User-agent: *
Allow: /
